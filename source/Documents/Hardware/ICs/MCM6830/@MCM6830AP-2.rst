.. image:: ../../../../images/Hardware/ICs/MCM6830/MCM6830AP-2.png
   :width: 400
   :align: center

.. note:: 
   
   This contains JBUG rev 1.8 9-6-76 (06-SEP-1976) as listed in the documentation linked below.
   This has been confirmed by examining each byte of the ROM area between $E000 and $E3FF and comparing
   the content to the assembly listing in the aforementioned document. Since the byte-for-byte comparison 
   showed no differences, it can be determined that the version of JBUG burned onto the ROM is 1.8.
