M68EXORSET(D1) EXORset Users Guide
==================================

.. include::  M68EXORSET(D1).carousel.rst

.. Important:: 
   The binder spine images are labeled as being for the EXORset 30 Development System.
   They are for the EXORSET 35.
   Motorola had not yet updated all their released documents when they produced these manuals.

.. note:: 
   
   Binder 1 contains the following documents:

   - :ref:`MSETBAS(S1) M6809 BASIC-M Interactive Compiler Supplement <MSETBAS(S1)>`
   - :ref:`M68MASR(D2) 6800/6801/6805/6809 Macro Assemblers Reference Manual <MSETBAS(S1)>`
   - :ref:`BASCNEWS(D2) BASICNEWS for BASIC-M <BASCNEWS(D2)>`
   - :ref:`MSET30BAS(D1) M6809 BASIC-M Interactive Compiler User's Guide <MSET30BAS(D1)>`
   - :ref:`M68SETEDITORM(D1) EXORset EDITOR Reference Manual <M68SETEDITORM(D1)>`
   - :ref:`MSETLLD(D1) XDOS Linking Loader Reference Manual <MSETLLD(D1)>`
   - :ref:`MSETPLOT1(D1) EXORset 30 PLOT 1 User's Guide <MSETPLOT1(D1)>`
   
   .. rubric:: Binder 2 contains the following documents:

   - :ref:`M68XDOS4(S1) Supplement to EXORset XDOS Operating System User's Guide <M68XDOS4(S1)>`
   - :ref:`M68SETDS35/D1 EXORset DS35 Development System User's Manual <M68SETDS35(D1)>`

   This document itself includes :

   - Disassembly diagrams
   - Program jumper settings
   - Pinouts
   - :download:`Schematics <../../../_static/Documents/Generic/EXORset_schematics.pdf>`
   - Parts lists
   - CRT data and service manual
   - Floppy drive diagrams and servicing information
